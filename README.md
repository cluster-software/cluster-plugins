# Cluster plugin — retired

The Cluster plugin and this marketplace are retired. Cluster supports direct
hosted MCP connections and the standalone CLI. No plugin installation is needed.

**[Connect to Cluster or migrate an existing plugin installation](./GETTING_STARTED.md).**

- MCP server: `https://api.ethos.hello-cluster.com/mcp`
- Transport: streamable HTTP; authentication: OAuth approved in the browser.
- CLI: [`ethos-cli` on npm](https://www.npmjs.com/package/ethos-cli).

This repository is retained for old links and migration instructions. The final
plugin manifests remain available for existing installations, but receive no
further releases. Archiving the repository does not uninstall a plugin or revoke
its MCP authorization. Tools and current workflow guidance come from the hosted
MCP server and do not depend on this repository.
